# План перехода на компонентную библиотеку Mantine

**Статус:** выполнен 2026-11-11. Миграция на Mantine завершена, поверх неё применён визуальный стиль по `docs/DESIGN.md`. Итог и отклонения — в разделе 9.

## 1. Выбор библиотеки

**Mantine 9.8.0** (`@mantine/core` + `@mantine/hooks`).

Почему:

- полностью покрывает элементы текущего интерфейса и не диктует компоновку;
- не требует Tailwind, Emotion и PostCSS: достаточно `import '@mantine/core/styles.css'` и `MantineProvider`;
- peer-зависимости совпадают с текущим React 19.3.1 (`react ^19.2.0`, `react-dom ^19.2.0`, `@mantine/hooks@9.8.0`);
- tree-shaking работает через ESM, бандл растёт умеренно.

### Доступность (проверено 2026-11-11)

| Пакет | Версия | React 19 | Комментарий |
|---|---|---|---|
| **@mantine/core** | **9.8.0** | требует `react ^19.2.0` — установлен 19.3.1, подходит | peer: `@mantine/hooks@9.8.0` |
| @mantine/hooks | 9.8.0 | `react ^19.2.0` | обязательный peer |
| @mui/material | 9.5.0 | `^17 \|\| ^18 \|\| ^19` | альтернатива, тянет Emotion |
| antd | 6.7.0 | `>=18` | избыточен: dayjs, cssinjs |
| @chakra-ui/react | 3.38.0 | `>=18` | Emotion + @ark-ui |
| react-bootstrap | 2.10.10 | `>=16` | нужен Bootstrap CSS |

Проверено дополнительно: registry npm доступен, `@mantine/core/styles.css` отдаётся (299 КБ, ~45 КБ gzip), установка через pnpm в проекте уже работает. Ничего не устанавливалось заранее — установка входит в первый шаг миграции.

## 2. Зависимости

```bash
pnpm add @mantine/core@^9.8.0 @mantine/hooks@^9.8.0
```

- Тип: `dependencies` (оба пакета нужны в рантайме).
- `devDependencies` не требуются. `postcss-preset-mantine` и `postcss-simple-vars` понадобятся только если позже захотим кастомизировать тему через Mantine-миксины в `.module.css`.
- Бандл: CSS +299 КБ raw (~45 КБ gzip), JS +40–60 КБ gzip; точные цифры замеряются после `pnpm build`.
- Запуск команд — через bundled Node/pnpm DSH; в песочнице `workspace-write` Vite падает на `spawn EPERM`, установка и сборка выполняются разово с расширенными правами (как и раньше).

## 3. Что заменяем

Тексты, URL, порядок элементов и логика не меняются.

| Сейчас | Компонент Mantine | Примечание |
|---|---|---|
| Кнопки «Сбросить», «Сохранить», «Отмена», «+ Добавить ингредиент» | `Button` | `variant="default"` / `variant="filled"`; `disabled` сохраняется |
| Кнопки «−» / «+» у порций, «×» удаления строки ингредиента | `ActionIcon` | те же `aria-label` |
| Ссылки-кнопки «+ Добавить рецепт», «← К списку рецептов», бренд «Recipe Box» | `Button` / `Anchor` c `component={Link}` | URL прежние |
| Поля «Название», «Количество», «Порции», «Название ингредиента» | `TextInput` | у порций остаётся `type="number"`, у количества — `inputMode="decimal"` |
| Единица измерения | `Select` | пустое значение «—» приводится к `null` только внутри формы, в данных остаётся `''` |
| Шаги | `Textarea` | `rows={6}`, текст-заглушка тот же |
| Чекбоксы фильтра «Что имеется?» | `Checkbox` | логика «И», счётчик и «Сбросить» без изменений |
| Таблица ингредиентов | `Table` | те же столбцы «Ингредиент» / «Количество» |
| Пометка «Ваш рецепт» | `Badge` | `variant="light"`, цвет зелёный |
| Ошибки полей и общая ошибка формы | `error`-проп у полей + `Alert color="red"` | формулировки дословно прежние |
| Карточка рецепта | `Card component={Link}` | ведёт на `/recipe/:id` |
| Панели, заголовки, подписи, пустые состояния | `Card`, `Title`, `Text` | только оформление |
| Список шагов | `List type="ordered"` | нумерация сохраняется |

**Отметка выполнения.** В приложении такого элемента нет: чекбоксы есть только в фильтре ингредиентов (выбор продуктов). Добавление отметки шагов/ингредиентов — новая функция, в этот план не входит и требует отдельного согласования.

## 4. Что не меняем

Маршруты и URL (`/`, `/recipe/:id`, `/add`, редирект с неизвестного пути), компоновку (две колонки на главной, одна при ширине < 720 px), все русские тексты и подписи, порядок блоков, состояние и логику (фильтр «И», порции 1–20, округление), localStorage-ключи `recipebox.v1.recipes` и `recipebox.v1.userId`, модель данных, 8 демо-рецептов, валидацию.

## 6. Риски и решения

- **Mantine 9 — мажорная версия.** API используемых компонентов стабилен, но проверяем сборкой и вручную. Откат локализован: удалить два пакета и вернуть прежний CSS.
- **`Select` и пустая строка.** Значение «—» приводится к `null` внутри формы, в модели данных единица остаётся `''`.
- **Конфликт глобальных CSS и Mantine.** Убираем глобальные правила для элементов, Mantine CSS подключаем первым, локальные стили — после.
- **Сохранность данных.** Формат localStorage не меняется, ключи прежние; после миграции существующие рецепты должны читаться без пересева.
- **Рост бандла.** Замеряем до/после; при заметном росте можно оставить только используемые компоненты (Mantine tree-shakeable).

## 7. Критерии готовности

1. `pnpm build` — код возврата 0; работают `/`, `/recipe/seed-plov`, `/add`, неизвестный путь редиректит на `/`.
2. Проверки PRD 1–3 дают те же числа: фильтр «курица» + «рис» → 2 рецепта; Плов 6 порций → рис 600 г, курица 900 г, морковь 3 шт; Брауни 5 порций → яйца 2,5 шт, шоколад 167 г; хлеб на 4 порции = 4 шт.
3. Все тексты и подписи совпадают с текущими.
4. Существующие рецепты в localStorage читаются, добавление нового работает, ключи не изменились.
5. Компоновка и брейкпоинт 720 px не изменились; новых функций нет (нет избранного, таймера, отметки выполнения).

**Отклонения от плана:**

- Добавлен `@fontsource/nunito-sans` — по согласованию выбрано локальное подключение шрифта вместо Google Fonts.
- Список шагов рецепта сделан семантическим `<ol>` вместо `List` из Mantine: у Mantine нумерация задаётся инлайн и дублировалась бы с бейджами; тексты и порядок не изменились.
- Кнопка «+ Добавить рецепт» уменьшена до 42 px по отдельной просьбе заказчика и выровнена по верхнему краю шапки.
- Заголовок в шапке 32 px вместо display 40 px — чтобы шапка не раздувалась.
- Поля формы 42 px: высота 48 px в `docs/DESIGN.md` задана только для «поля поиска», которого в приложении нет.
- Фотографии, миниатюры, чипы категорий и плитки ингредиентов не внедрялись: фото вне объёма, плитки изменили бы компоновку.
- 2026-11-17: `AddRecipeForm` переименован в `RecipeForm` — общая форма для добавления и редактирования (`initialValues`); `EditPage`, `/recipe/:id/edit` и error boundary собраны из тех же Mantine-компонентов, новых библиотек нет.
